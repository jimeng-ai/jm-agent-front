# jm-agent-front v1.1.0 上线说明

> 发版：`nvm use 20` 后执行 `npm run release -- minor --notes-file docs/releases/v1.1.0.md`。
> **先发 data-service v1.1.0**：这一版用到的数据星图接口新字段、AI 生成 Skill 的新接口都在那一版里。
> 这一轮四个仓库的完整上线步骤（生产 DDL、发版顺序、上线后核对、回滚）见 data-service 的 `docs/releases/v1.1.0.md`。

## 这一版包含什么

线上现在是 v1.0.0（2026-09-21 部署的 `ec83939`）。v1.1.0 带上之后合进 main 的全部改动：

- **数据星图改为用业务说法的对象关系图**：对象卡片（业务名、一句说明、领域色条）；两个对象之间同一方向的关系合成一根线，
  线上写角色名；领域筛选；对象详情依次是「它是什么 / 和谁有关 / 技术信息（默认折叠）」；默认视图不出现表名、字段名；
  入口在「数据连接」里每个库的卡片上（「查看星图」，一个库一页），侧栏不单列；和数据连接一样只给企业超管。
- **2026-09-27 合进 main、一直没上线的 17 个提交**（当时的部署被取消）：
  - 智能体管理工作台、连接控制面改版，侧栏导航的基础；
  - 语义控制室；
  - 登录会话隔离、流式响应按会话鉴权、智能体退出保护；
  - 语义工作台与运行时契约对齐、JOIN 载荷可见性、结构刷新受限时的说明；
  - AI 创建与审查流程重做（配合 data-service 的 AI 生成 Skill 改版）。
- 发版方式改为推 tag 才部署。

## 上线后先点一遍

数据星图（数据连接 → 数据库卡片上「查看星图」）、智能体工作台、连接管理、语义控制室、AI 生成 Skill（沙箱 v1.1.0 发成功之后）。

## 回滚

GitHub → Actions → Deploy → Run workflow，在 Use workflow from 里选 `v1.0.0`。会连带撤掉上面全部改动。
